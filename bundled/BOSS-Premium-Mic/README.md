# BOSS Premium Mic

A rebranded WhatsApp Web microphone-processing extension based on the supplied project. It uses high-output gain with compressor/limiter protection; it cannot guarantee a fixed sound-level increase because microphones, devices, and call settings vary. Keep speaker volume comfortable.

telegram:- t.me/BOSSX929

© BOSS X

Load the extracted folder as an unpacked extension in a compatible Chromium browser, open WhatsApp Web, reload the tab, and test with a trusted contact.


WhatsApp calls: the extension processes the microphone audio sent by WhatsApp Web through the BOSS X PRIME DSP chain (EQ, compressor, loudness, saturation, sustain and limiter). Incoming caller audio is playback audio and is not the microphone signal; a normal content-script microphone extension cannot replace the phone/browser system output path.
